# 京房六十四卦配二十八宿规则

> 状态：三处纠错已由项目发起人确认，规则 v1 已实现  
> 文档版本：1.1.0  
> 最近更新：2026-08-05  
> 适用范围：六十四卦世爻配宿、六爻逐爻装宿  
> 不适用范围：万年历值日宿、五星入卦、吉凶解释  
> 规则输入：项目发起人提供；本文为工程化整理  

## 1. 目的与边界

本文把项目发起人提供的“京房六十四卦配二十八星宿”规则整理为可复算、可测试、可追踪的工程规格。

本规则解决两个问题：

1. 每一重卦的世爻从哪一宿起配。
2. 确定世爻宿后，同一卦其余五爻如何依次装宿。

这里的入卦宿是卦爻属性，不等于万年历某日的值日宿。当前资料也没有定义五星、建候、积算或吉凶判断，因此这些内容不得由本规则推断。

## 2. 二十八宿固定顺序

计算顺序固定为：

```text
角 → 亢 → 氐 → 房 → 心 → 尾 → 箕
→ 斗 → 牛 → 女 → 虚 → 危 → 室 → 壁
→ 奎 → 娄 → 胃 → 昴 → 毕 → 觜 → 参
→ 井 → 鬼 → 柳 → 星 → 张 → 翼 → 轸
→ 回到角
```

| 方位 | 七宿 | 全局序号（从 1 起） |
|---|---|---|
| 东方七宿 | 角、亢、氐、房、心、尾、箕 | 1–7 |
| 北方七宿 | 斗、牛、女、虚、危、室、壁 | 8–14 |
| 西方七宿 | 奎、娄、胃、昴、毕、觜、参 | 15–21 |
| 南方七宿 | 井、鬼、柳、星、张、翼、轸 | 22–28 |

若绘制二十八宿空间环，应从东南角放置角宿，随后逆时针排列。空间位置只影响图形展示，不改变上述线性计算顺序。

## 3. 第一步：确定六十四卦世爻宿

### 3.1 六十四卦遍历顺序

八宫顺序固定为：

```text
乾宫 → 震宫 → 坎宫 → 艮宫 → 坤宫 → 巽宫 → 离宫 → 兑宫
```

每一宫内部固定按以下八个宫内序位遍历：

```text
本宫六世 → 一世 → 二世 → 三世 → 四世 → 五世 → 游魂 → 归魂
```

因此共有一个稳定的 0–63 全局卦序。乾为天是第 0 位，其世爻从参宿起；后续每一卦在前一卦世爻宿的基础上顺推一宿，轸宿之后回到角宿。

若二十八宿采用从 0 开始的索引，角为 0、参为 20，则：

```text
世爻宿索引 = (20 + 六十四卦全局序号) mod 28
```

## 4. 第二步：给一卦六爻逐爻装宿

### 4.1 总原则

1. 世爻装本卦的世爻宿，记为装配次序 1。
2. 应爻装二十八宿顺序中的下一宿，记为装配次序 2。
3. 将世爻所在经卦称为“世卦”，应爻所在经卦称为“应卦”。
4. 之后在世卦和应卦之间交替装配：世卦剩余一爻、应卦剩余一爻、世卦最后一爻、应卦最后一爻。
5. 内卦的剩余爻按初爻到三爻的方向排列；外卦的剩余爻按上爻到四爻的方向排列。已经作为世爻或应爻使用的位置跳过。
6. 六个宿始终按二十八宿固定顺序连续取值，轸后回角。

装配顺序是：

```text
世 → 应 → 世卦剩余第1爻 → 应卦剩余第1爻
→ 世卦剩余第2爻 → 应卦剩余第2爻
```

### 4.2 按世爻位置得到六个装配爻位

| 世爻位置 | 应爻位置 | 六个装配爻位顺序 |
|---:|---:|---|
| 初爻 | 四爻 | 初、四、二、上、三、五 |
| 二爻 | 五爻 | 二、五、初、上、三、四 |
| 三爻 | 上爻 | 三、上、初、五、二、四 |
| 四爻 | 初爻 | 四、初、上、二、五、三 |
| 五爻 | 二爻 | 五、二、上、初、四、三 |
| 上爻 | 三爻 | 上、三、五、初、四、二 |

游魂卦世在四爻，使用“四爻”行；归魂卦世在三爻，使用“三爻”行。

### 4.3 伪代码

```text
MANSIONS = [角, 亢, ..., 翼, 轸]
PALACES = [乾宫, 震宫, 坎宫, 艮宫, 坤宫, 巽宫, 离宫, 兑宫]

global_hexagram_index = palace_index * 8 + palace_sequence_index
world_mansion_index = (index_of(参) + global_hexagram_index) mod 28

placement_positions = positions_for_world_line(world_line_position)

for offset in 0..5:
    line_position = placement_positions[offset]
    mansion = MANSIONS[(world_mansion_index + offset) mod 28]
    place mansion on line_position
```

## 5. 固定样例

### 5.1 乾为天

乾为天是全局第 0 卦，世在上爻，世爻宿为参。六个连续宿为：

```text
参、井、鬼、柳、星、张
```

上爻世的装配爻位顺序为：

```text
上、三、五、初、四、二
```

最终逐爻结果为：

| 爻位 | 星宿 | 装配身份 |
|---|---|---|
| 上爻 | 参 | 世 |
| 五爻 | 鬼 | 世卦剩余第1爻 |
| 四爻 | 星 | 世卦剩余第2爻 |
| 三爻 | 井 | 应 |
| 二爻 | 张 | 应卦剩余第2爻 |
| 初爻 | 柳 | 应卦剩余第1爻 |

### 5.2 世爻虚宿在二爻

若某卦世爻在二爻且世爻宿为虚，则六个连续宿为：

```text
虚、危、室、壁、奎、娄
```

二爻世的装配爻位顺序为：

```text
二、五、初、上、三、四
```

最终结果为：二爻虚、五爻危、初爻室、上爻壁、三爻奎、四爻娄，与用户给出的第二个样例一致。
