# 项目术语表

> 状态：`Draft`  
> 最近更新：2026-08-05

| 标准术语 | 本项目含义 | 避免混用 |
|---|---|---|
| 排盘 | 根据起卦输入与时间上下文生成六爻卦面 | “排班”仅视为语音/输入误差 |
| 起卦 | 获得六个原始爻值的过程 | 不等同于完整排盘 |
| 起卦记录 | 模式、六次原始输入、标准爻值、时间和版本 | 不只保存最终卦名 |
| 本卦 | 六个原始爻构成的卦 | 主卦可作为界面别名，但数据字段统一 |
| 变卦 | 动爻阴阳变化后形成的卦 | 无动爻时的显示策略待 Spec 确认 |
| 动爻 | 某一爻开启“动”状态；阴动为老阴 6，阳动为老阳 9，并在变卦中阴阳反转 | 不把所有阴/阳爻称为动爻；“动”不直接改写本卦爻形 |
| 卦宫 | 八宫体系中卦的归属 | 与上卦/下卦不是同一概念 |
| 世爻/应爻 | 卦宫体系确定的世、应位置 | 与世身不同 |
| 纳甲 | 将天干地支纳入各爻的规则体系 | 不将干支五行拼为一个不可解析字段 |
| 六亲 | 以宫五行与各爻五行生克关系确定 | 与现实亲属关系解释分开 |
| 六神 | 依据日干按爻序布置的六神体系 | 规则来源需冻结 |
| 伏卦 | 本卦内、外卦分别与所属宫经卦比较后，按“相同取错卦、不同取宫卦”组合出的完整卦 | 不等同无条件取八纯卦；详见 `fu-gua-rule.md` |
| 伏神 | 伏卦六爻纳甲后，以本卦宫五行确定六亲并逐位伏于本卦飞神的结构 | 新盘固定展示六条；不再只补缺失六亲 |
| 五行十二长生 | 以五行映射十二阶段的当前目标体系 | 不等同十天干阴阳顺逆十二长生 |
| 神煞 | 按已冻结输入与查表规则产生的辅助命中 | 不自动等同吉凶结论 |
| 卦身/挂身 | 疑似同一术语的原文与规范名候选 | 未确认前不静默改名 |
| 世身 | 独立辅助结构 | 不等同世爻、卦身 |
| 值日二十八宿 | 万年历中特定日期对应的值宿 | 不等同六爻二十八宿入卦 |
| 二十八宿入卦 | 把宿或相关体系映射到卦/爻的高阶规则 | 算法尚未确定 |
| 解读 | 用户对当时卦面的判断、分析或笔记 | 不等同事后反馈 |
| 反馈 | 事情发展后记录的现实结果 | 不反向修改原始卦面 |
| 计算明细 | 输入、中间量、查表项、规则版本和输出的可追溯记录 | 不只是自然语言结论 |
| 规则包版本 | 一组可确定复现结果的规则集合标识 | 不用 App 版本替代 |
| 卦面快照 | 案例保存时的完整结构化排盘结果 | 不在读取时静默重算 |

若后续确认别名，应保留：规范名、用户显示名、历史别名和来源，不直接批量改写旧档案文本。
