# SPEC-004 规则来源与实现状态审计

> 状态：`Active`  
> 版本：0.8  
> 最近更新：2026-08-07  
> 作用：把用户指定名称、可定位原文、现代候选取法和实际代码状态分开记录

## 1. 本轮结论

1. 五行十二长生已有可定位古籍依据，可先作为独立规则包实现。
2. schema v14 起木火金水顺行，辰戌丑未按 SRC-020/021 四土本气表；旧“土申起统一顺行”只属于历史 v1。
3. 每个本卦爻以爻五行为主体，分别对年、月、日、时四柱地支计算；变卦爻暂不进入 v1。
4. 用户指定的 20 个名称继续全部保留，但不能被当成一套已经统一的“十三神煞 + 七项附加规则”。其中有别名、异法和输入锚点未定问题。
5. 历史上禄神、天乙、驿马、桃花、将星、华盖均有独立规则包；DEC-049 起新盘产品只输出驿马、桃花、禄神、华盖、天乙贵人，另以独立辅助结构输出卦身、命爻。将星仍可审计旧快照，但不进入新结果。
6. 驿马 v1 只取项目日支：SRC-016 在六爻占卦语境中明确举“子、申、辰日占卦，爻中见寅”；年支与年日并取不进入本规则包。
7. 桃花 v1 的产品显示名为“桃花”、规范名为“咸池”；SRC-015 第 111 页明确以日支为标尺。月支、年支以及月日并取属于冲突候选，不进入本规则包。
8. 将星 v1 只取项目日支：SRC-011 节点 0333 与马前神杀第十一位给出同一四组表，SRC-015 第 111 页明确现代六爻以日支为标尺；出师章的农历月序将星另设候选规则 ID，不在 v1 混算。
9. 华盖 v1 只取项目日支：SRC-011 马前神杀第三位与 SRC-015 第 111 页四组表一致；SRC-018《易林补遗》农历月序华盖另设候选规则 ID，不在 v1 混算。
10. 当前“卦身”规范为月卦身，SRC-024 明确其与世爻之身是不同结构；命爻使用 SRC-020 中已版本化的所选传本映射，权威等级保持 C，不扩展解释。

## 2. 可定位证据

### SRC-011：古籍收录页

《钦定古今图书集成·博物汇编·艺术典》第 557 卷收录《卜筮全书十四》的“神杀歌例”与“五行长生”。可定位内容包括：

- 天元禄：卷页行 408–412。
- 驿马：行 416–420。
- 天乙贵人：行 424–428。
- 天喜：行 471–475，使用四季表。
- 天医：行 496–500，使用独立逐月表。
- 劫杀、咸池杀：行 767–779。
- 马前神杀：行 947–953，包含驿马、华盖、劫杀、灾杀、将星的顺轮关系。
- 五行长生：行 967–973，明确木亥、火寅、水土申、金巳起且皆顺行。

公开转录页说明原本无标点，现有标点经过后期处理。因此实现只采用查表关系，不把页面标点当作规则的一部分；同时用 SRC-012 本地结构化快照交叉检查。

### SRC-012：本地结构化快照

Taoracle `src-backend/app/data/liuyao_index.json`：

- `source_title`：卜筮全书。
- `source_path`：卜筮全书.md。
- `version`：1。
- `generated_at`：2026-03-08T18:12:45.936421+00:00。
- 结构节点 1,349 个、检索条目 6,749 条。

相关节点：0333（国朝章将星四组表）、1104（天元禄、驿马、天乙）、1105（天喜）、1106（天医）、1113（咸池杀）、1124（马前神杀）、1127（长生沐浴）、1159（出师征伐章月序将星）、1266/1340（月序华盖）。其中节点 1113、索引行 11527 给出咸池表；节点 1124、索引行 11741 记“三华盖、十一将星”。该文件是项目衍生索引，只作为可复查快照，不替代古籍来源。

### SRC-016：《增删卜易·星煞章》

SRC-011 的驿马条给出“申子辰马居寅”等四组查表，但条内没有明写年支还是日支。SRC-016 在“占卦”语境中直接举例：子、申、辰日占卦，爻中见寅即为驿马。这一输入锚点与 SRC-015 现代六爻对标资料的“以日支为标尺”一致。

因此 v1 采用日支，并把年支或年日并取视为其他命理系统/规则包的候选，不在当前六爻结果里合并。

### SRC-015 与 SRC-017：桃花/咸池

已将 SRC-015 固定为朱辰彬《古筮真诠（总论易理篇）》网络 PDF：共 906 页，SHA-256 为 `e7b5d62344d16a54299272989835bf227ea3fc79ec44d5e7b40b8bc368247687`。PDF 第 111 页在六爻神煞段明确写明以日支为标尺，并给出申子辰→酉、巳酉丑→午、寅午戌→卯、亥卯未→子。

SRC-011 本地快照节点 1113 的“咸池杀”给出同一四组表；SRC-017《神峰通考》用于确认“桃花煞，一名咸池杀”的名称关系。后者属于命理古籍语境，只用于规范名和别名，不反向决定六爻输入锚点。

另有现代六爻资料主张申/月或申/日均可起桃花。为避免把两套输入混成一个不可复核结果，v1 只采用 SRC-015 的项目日支口径。固定冲突样例为 2026-08-06：项目月支未会取桃花子，项目日支子会取桃花酉；同一泽天夬明爻同时有初爻子与五爻酉，两个口径会命中不同爻位，证明不能静默合并。

### 将星同名异法审计

SRC-011 节点 0333 直接给出“寅午戌午、巳酉丑酉、申子辰子、亥卯未卯”；节点 1124 又从各组三合局驿马位顺轮到第十一位将星，推导结果完全一致。SRC-015 第 111 页则在现代六爻神煞段明确写“以日支为标尺”，因此通用标注 v1 采用项目日支。

同一 SRC-011 的节点 1159 还存在出师征伐专用月序规则：正月午、二月卯、三月子、四月酉，之后四位循环。这是按农历月序起例，不是日支三合局规则。候选规则 ID 预留为 `shensha.jiangxing.lunar_month.military.v1`，本轮不实现。

固定冲突样例为 2026-08-06 15:26、山地剥 `[8,8,8,8,8,7]`：项目日支子取将星子，命中五爻甲子；农历六月的出师月序将星为卯，会命中三爻乙卯。两套规则命中不同爻位，证明必须分包而不能合并。

### 华盖同名异法审计

SRC-011 节点 1124 以各组三合局驿马位为第一位，顺轮到第三位华盖，得到申子辰→辰、巳酉丑→丑、寅午戌→戌、亥卯未→未。SRC-015 第 111 页在现代六爻神煞段明确以日支为标尺，四组结果一致，因此通用标注 v1 采用项目日支。

SRC-018《易林补遗》另有农历月序起例：正月戌、二月未、三月辰、四月丑，之后四位循环。Taoracle 节点 1266 把“戌”误转为“戊”，节点 1340 与 SRC-018 可纠正此字。候选规则 ID 预留为 `shensha.huagai.lunar_month.v1`，本轮不实现。

固定冲突样例为 2026-08-06 15:26、火天大有 `[7,7,7,7,8,7]`：项目日支子取华盖辰，命中三爻甲辰；农历六月的月序华盖为未，会命中五爻己未。两套规则命中不同爻位，必须分包。
