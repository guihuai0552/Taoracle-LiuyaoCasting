# `liuyao-private` 纯 Dart 移植与规则审计

> 状态：`Implemented / Audited`  
> 日期：2026-08-07  
> 参考副本：仓库外维护的 `liuyao-private` 本地副本（`LIUYAO_PRIVATE_ROOT`）  
> 固定提交：`6ca3d3e`  
> 规则：该副本是可执行对照，不是传统规则的最终权威。

## 1. 本轮目标

把私有 Python 副本中可执行、可测试的六爻和万年历规则逐项移植为纯 Dart，供离线
Flutter 应用直接调用。移植不是“照抄即真理”：凡与现有合同、经典文献或实际依赖行为
冲突的地方，都必须保存来源、版本、分歧和选择理由，并用固定输入验证。

生产唯一运行时仍为 `packages/liuyao_engine`。私有 Python 副本和其依赖只在开发期用于
差异对照，不进入 APK。

## 3. 验证结果

使用私有副本测试所依赖的 Python 环境（`lunar_python==1.4.8`、`cnlunar==0.2.0`）验证：

- 私有 Python 自身：54 项测试全部通过；
- 64 个静态卦盘：`plate` 完整字典逐字段相等；
- 固定动爻样例：卦盘、机械关系、三个扩展完整字典逐字段相等；
- 十二长生：5 五行 × 12 地支，共 60 项；连同重复查询域共核验 144 对；
- 纳音：60 甲子全部相等；
- 历法：7 个普通/边界时刻逐字段核对；
- 交节：1901–2099 共 2,388 个“前一秒/当秒”边界全部相等。

复现命令：

```bash
LIUYAO_PRIVATE_ROOT=<本地副本路径> python3 \
  scripts/check_private_reference_dart_parity.py
```

精确交节常量不是手工录入。生成器固定 `lunar_python==1.4.8`，输出中保存版本、生成范围
和内容 revision：

```bash
LIUYAO_PRIVATE_ROOT=<本地副本路径> python3 \
  scripts/generate_exact_jie_table.py
```

## 4. 冲突、核验与决定

### 4.1 土十二长生

旧产品把土统一寄水并顺行。私有副本按辰、戌、丑、未四土本气分别起表；这与
《五行大义》卷二列出的四土十二辰状态一致。本轮改为四土本气表，结果保存
`source_model=four_earth_native`，不再把旧口径静默当作同一版本。

### 4.2 天乙贵人

私有规则包采用“甲戊庚牛羊、六辛马虎”支表，因此庚为丑未、辛为寅午。旧产品曾把
庚误接到午寅。本轮按私有规则包修正，并通过固定日干测试锁定；其他口诀流派未来必须
使用新规则 ID，不能覆盖本结果。

### 4.3 日界说明与可执行行为不一致

私有 profile 文案写 `civil_midnight`，但其实际 `cnlunar` 计算在 23:00 已切换日柱。
为复刻真实可执行输出，Dart 采用 23:00 子初换日，并把口径如实标为
`zi_initial_23_cnlunar_compat`。文案值不再冒充运行行为。

### 4.4 伏神与产品完整伏卦

私有副本的 `hidden_spirits` 只列本卦缺失六亲；产品已按用户确认规则展示完整六爻伏卦。
两者用途不同，schema v14 起同时保存：

- 产品 `hexagram.base.lines[].hidden`：完整六爻伏卦，用于卦面；
- `private_reference_contract.plate.base.lines[].hidden_spirits`：私有副本缺失六亲口径，
  用于精确对照。

任何一方都不得覆盖另一方。

### 4.5 二十八宿不是一个算法

私有副本只输出 cnlunar 的“值日宿”。产品中已有用户确认的京房六十四卦逐爻装宿。
前者属于万年历 provider 扩展，后者属于排盘注解；字段、规则 ID 和 UI 含义保持分离。

### 4.6 纳音用字

私有副本使用“泉中水、沙中金、沙中土”。产品采用这些规范显示名，同时保留
“井泉水、砂中金、砂中土”作为导入/旧快照别名，不改写历史档案。

### 4.7 历法边界

年柱以立春、月柱以十二“节”精确到秒切换。上海历史时区包含 1919 等 DST 变化；
Dart 交节比较先将墙上时间按对应历史 UTC offset 反解，不能假定全时期固定 `+08:00`。
香港天文台的官方资料用于独立抽查二十四节气日期与东八区说明；程序级逐秒基线固定为
`lunar_python==1.4.8`，更换版本必须重新生成并跑完边界矩阵。

## 5. 尚未声称完成的规则

私有副本中没有羊刃、灾煞、文昌、天喜、天医、劫煞、谋星、独立沐浴杀、金鱼、鸿雁、
床帐、香归等完整可执行表，也没有天文五星入卦。它们继续保持“未计算”，不能因为副本
名为“完整”就补造输出。需要逐项取得来源、流派、输入锚点和固定样例后另建规则版本。

## 6. 合同与兼容

- 新排盘：当前 schema v16，engine `0.16.0+three-layer-annotations`；私有参考合同本身仍锚定 schema v14 引入的 `6ca3d3e` 版本；
- 新增 `private_reference_contract`，保存来源提交和 port language；
- 每条本卦、变卦、完整伏卦纳甲记录新增 `nayin`；
- 旧 schema v1–v15 快照只读兼容，不自动补算或改写；
- 当前私有参考合同不是对外开源 API 承诺。未来公开仓库可按许可证和产品边界拆分，
  但私有应用中的规则不会因此被人为删除。
