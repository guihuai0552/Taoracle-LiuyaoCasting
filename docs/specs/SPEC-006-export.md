# SPEC-006 档案导出

> 状态：`Implemented Baseline / UI Review`  
> 版本：0.4  
> 最近更新：2026-08-07  
> 依赖：SPEC-005

## 1. 目的

让用户一键导出完整案例，既能阅读、打印和分享，也能保留可迁移、可复算的结构化数据。

## 2. 范围内

- 从单个案例发起导出。
- 从档案页批量导出和导入完整迁移包。
- 选择导出内容：占问信息、起卦记录、卦面、计算明细、解读、反馈。
- 至少一种人类可读格式和一种机器可读格式。
- 导出预览、隐私提示、生成状态、失败重试和系统分享。
- 导出文件带 schema 版本、规则版本和生成时间。
- 单档案可导出适合直接分享的 PNG 长图。

## 3. 范围外

- 公开网页分享链接。
- 自动上传第三方网盘。
- 去标识化研究数据集。

## 4. 格式候选

| 格式 | 用途 | 首版状态 |
|---|---|---|
| PDF | 阅读、打印、分享 | 后续切片，当前未实现 |
| JSON | 完整数据、迁移、复算 | 已实现 |
| Markdown | 可编辑文本和知识库 | 已实现，作为当前人类可读格式 |
| 图片（PNG 长图） | 快速分享完整卦面、解读和反馈 | 已实现 |
| 批量迁移 JSON | 全量备份和跨设备恢复 | 已实现 |

所有格式均完全在设备端生成，再交给系统分享或原生文件选择器；不上传远程服务。JSON 保留原始起卦记录、完整版本化卦面快照、规则版本、计算轨迹、解读和反馈。

档案详情可选择 Markdown、单档 JSON 或 PNG 长图并交给系统分享面板。档案页提供“批量导出全部档案”和“导入档案迁移包”；迁移格式见[档案迁移格式 v1](../architecture/archive-transfer-format.md)。

## 5. 关键要求

- `FR-EXP-001` 当前导出选择页明确说明包含占问、原始起卦、卦面、解读、反馈与计算依据；更细的隐私确认后续补齐。
- `FR-EXP-002`（2026-09-04 已实现）导出面板提供「包含解读与反馈」开关：关闭后 Markdown 与 PNG 长图只含卦面与占问信息；JSON 保持完整数据不受该开关影响。脱敏模式仍属后续范围。
- `FR-EXP-003` JSON 不得只导出界面文案，必须包含稳定字段、枚举和版本。
- `FR-EXP-004` 人类可读格式需保持上爻到初爻的正确视觉顺序。
- `FR-EXP-005` 生成失败不得产生看似成功的空文件。
- `FR-EXP-006` 同一案例、同一模板版本的内容语义一致。
- `FR-EXP-007`（2026-09-04 修订）PNG 长图包含占问、起卦时间、四柱旬空、本伏本变六爻表，并按导出选项决定解读与反馈区块：默认全部历史版本与全部反馈；关闭历史版本时解读只画最新一版；关闭解读与反馈时两个区块整体不绘制。仍保持上爻到初爻顺序。
- `FR-EXP-008` 批量迁移包固定包含完整记录，不提供可能误删解读或反馈的内容裁剪开关；单档 JSON 导出同属备份语义，忽略内容裁剪参数。
- `FR-EXP-009` 导入文件按严格 UTF-8 解码，允许 UTF-8 BOM，拒绝非法字节、未知版本、数量不一致和不完整案例。
- `FR-EXP-010` 首次使用导出时弹一次性选择框确定「解读历史版本」默认口径（包含全部历史版本 / 仅最新版本），选择写入偏好并在设置页可修改；之后每次导出面板的历史版本开关以上述默认值为初始值，单次可临时切换。
- `FR-EXP-011` 导出内容选项仅裁剪分享格式（Markdown/PNG）的人类可读呈现，不得影响设备端存储、批量迁移与导入合并的完整性。

## 6. 验收重点

- 含六爻、伏神、全部规则标注、长解读和多条反馈的案例能完整导出。
- JSON 通过 schema 校验并可恢复全部核心字段。
- Markdown 保持上爻到初爻的阅读顺序；JSON 保留原始初爻到上爻稳定数组和 schema/规则版本。
- PDF、内容勾选与匿名导出不属于当前基础审阅切片。
- 批量包在空白数据源导入后，档案数、卦面 JSON、全部解读版本和全部反馈必须与导出前一致。

## 7. 当前实现合同

- 当前生产实现完全离线，由同一个 `ArchiveDataSource` 读取本地案例并生成 Markdown、JSON、PNG 或批量迁移 JSON，不经过 HTTP/API。
- PNG 使用 Flutter Canvas 直接绘制动态高度长图，不依赖屏幕截图长度，避免折叠区和屏外信息丢失。
- 批量迁移包使用 `format=liuyao_archive_transfer`、`schema_version=1`，包含显式 `case_count` 与完整 `cases` 数组。
