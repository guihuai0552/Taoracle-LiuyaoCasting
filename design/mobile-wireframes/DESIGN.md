# 六爻移动端 Design System v0.2

> 状态：`Wireframe Candidate / 04A 第二轮评审`  
> 日期：2026-08-06  
> 视觉关键词：中式窗棂网格、黑白水墨、宣纸留白、羊皮纸卷、朱砂印记

## 1. 设计原则

1. **术数数据先于装饰**：卦名、爻象、六亲、纳甲、世应和动爻必须先清楚，再出现纹样。
2. **格中有序**：用中式窗棂的分格逻辑组织高密度信息，不把纹样直接铺在正文后方。
3. **墨分五色**：主要层级靠黑、深墨、淡墨和留白建立；朱砂只标当前、动爻、错误和主操作。
4. **纸有层次**：页面基底统一为宣纸米白，羊皮纸只用于需要强调“文档/展开”语义的容器，不再把黄褐色铺满卡片。
5. **古意不牺牲可读性**：篆书、印章字只用于图标或一至四个字的标签；正文与数字使用宋体/黑体系统字体。

## 2. 栅格

- 设计基准：360dp × 800dp，左右安全边距 16dp。
- 基础单位：4dp；常用节奏 8 / 12 / 16 / 24 / 32dp。
- 页面内容：12 列流式网格，列间距 8dp。
- 高密度卦面在 332dp 内容宽度中使用六个逻辑区：`六神 34 / 伏神 54 / 本卦 68 / 本卦爻象+世应 40 / 变卦 68 / 变卦爻象 24`。
- 卡片之间 12dp；同一卡片主次行之间 4–6dp。
- 底部导航固定 64dp，系统手势安全区另计。

## 3. 色彩 Token

| Token | 色值 | 用途 |
|---|---|---|
| `ink-950` | `#1C1C1C` | 标题、爻线、强边框 |
| `ink-800` | `#3A3A3A` | 正文、主要图标、窗棂基色 |
| `ink-600` | `#5C5C5C` | 次级信息 |
| `ink-300` | `#D0D0D0` | 分隔线、禁用态 |
| `paper-50` | `#F5F0E6` | 页面宣纸底色 |
| `paper-100` | `#F8F4E8` | 普通卡片与卦面底色 |
| `parchment-100` | `#F2E8D5` | 长文、导出和展开容器 |
| `cinnabar-700` | `#B22222` | 主操作、动爻、当前态、印章 |
| `jade-700` | `#3F6250` | 成功、已保存辅助状态 |

五行颜色只作为天干地支的小面积辅助编码，永远同时保留文字：木 `#347445`、火 `#C23A32`、土 `#8B7668`、金 `#D49A26`、水 `#216B9B`。五行色不用于大面积底色。

## 4. 字体层级

| 样式 | 建议 | 使用位置 |
|---|---|---|
| `display` | 28/34，宋体，700 | 页面主标题 |
| `title` | 20/26，宋体，700 | 卦名、日期、档案标题 |
| `body` | 15/22，宋体或系统黑体，500 | 占问、说明 |
| `data-primary` | 16/20，宋体，700 | 六亲纳甲、四柱 |
| `data-secondary` | 11/15，黑体，500 | 五行、十二长生、宿、来源 |
| `label` | 12/16，黑体，600 | 栏头、按钮、状态 |
| `seal` | 12/14，宋体，700 | 分类印记，最多四字 |

数字、时间和版本号使用等宽数字特性；关键正文不得依赖装饰字体。

## 5. 形状与纹样

- 普通卡片：12dp 圆角、0–1px 淡墨边线；不使用大面积阴影。
- 档案卡：12dp 圆角，左侧方形“分类印记”，右侧严格两行网格。
- 卷轴卡：顶部/底部双线和 8dp 内缩端头表现卷轴，不使用图片材质。
- 窗棂分隔：只出现在卡片边框、页头角标和空白区，使用 `#3A3A3A` 8%–12% 透明度，线宽 0.8px；高密度卦面背景禁止铺网格。
- 爻线：实线/断线本身是数据，不增加渐变、阴影或拟物纹理。
- 圆角胶囊仅用于短状态；主要按钮为 6dp 圆角矩形。

## 6. 核心组件

### 6.1 `ArchiveRecordTile`

- 左：64×64 分类印记；无分类时使用“卦”通用印。
- 右上：占问事项，单行优先、最多两行。
- 右下左：起卦时间。
- 右下右：`本卦 → 之卦`；静卦显示“静卦”。
- 整卡点击进入档案详情；长按不承担删除，避免误触。

### 6.2 `HexagramLedger`

- 卦面大卡顶部先显示四柱与逐柱旬空，再居中并列本卦、变卦与各自卦宫序位。伏卦名称作为全伏神栏的说明信息，不和本变卦抢主标题。
- 六行固定上爻至初爻；逻辑列为六神、伏神、本卦、本卦爻象+世应/动爻、变卦、变卦爻象。
- 每个“伏神/本卦/变卦”单元使用两级文字：主行六亲+干支，副行五行+十二长生/宿等。
- 动阳 `Ｏ`、动阴 `×` 位于本卦爻象右侧；世/应与动爻共用独立中心带，但不覆盖爻线。
- 逐爻细分线采用点线；上下卦之间用更深实线。

### 6.3 `ParchmentSection`

- 用于四柱、规则摘要、解读、反馈、计算明细。
- 标题始终在卷轴外缘或上边线内，展开状态有文字和方向箭头双提示。
- 折叠时保留一行摘要，不显示伪造的计算结果。

### 6.4 `PrimaryAction`

- 朱砂底、纸白字、最小高度 48dp。
- 一屏最多一个朱砂主操作；次操作用墨色描边。

## 7. 状态

- 当前/选中：朱砂短线、印记或边框，不整页染红。
- 已保存：玉色文字 + “已存本机”，不只显示图标。
- 动爻：符号 + 朱砂，确保黑白模式仍可识别。
- 空档案：保留分类印记轮廓和“完成起卦后自动保存”的明确说明。
- 错误：保留原数据，不用空状态覆盖；朱砂边框 + 可重试动作。
- 加载：骨架沿真实网格排列，避免整卡转圈。

## 8. 动效与无障碍

- 卷轴展开 180–240ms，使用高度与透明度，不模拟卷纸旋转。
- 触控目标不小于 44×44dp。
- 正文与背景对比至少 4.5:1；五行色不得成为唯一信息来源。
- 系统字体放大至 1.3× 时，档案卡允许增高，卦面主表保持列关系并优先缩短副行。
- “减少动态效果”开启时取消卷轴过渡，只做瞬时展开。

## 9. 本轮明确不做

- 写实毛笔飞白覆盖正文。
- 大面积仿古污渍、烧焦边缘、龙纹背景。
- 以竖排正文承载操作流程。
- 为追求古风而缩写六亲、六神或隐藏计算字段。

## 10. Flutter 组件落地映射

- `AppPaperScaffold`：统一 `#F5F0E6` 页面底，可叠加极淡宣纸纹理，不在高密度正文区铺纹样。
- `ChineseLatticePainter`：项目自有 `CustomPainter`，从回纹/窗棂边角开始；首版不强制引入图案依赖。
- `PaperCard`：米白卡、12dp 圆角、可选淡墨线，用于十二长生、神煞和卦面大卡。
- `ParchmentSection`：仅用于长文阅读、导出摘要和折叠内容；不在主卦面做真实翻页。
- `HexagramLedger`：固定六行的语义表格，可用 `LayoutBuilder + CustomMultiChildLayout`，不使用水平滚动。
- `pattern_box` 仅作为 `ChineseLatticePainter` 实现时的候选参考；`real_page_flip` 和 `paperfold_list` 不进入首版核心交互，避免影响阅读稳定性与无障碍。
